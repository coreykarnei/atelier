Code, shell, agent — side by side

One window. One clipboard. Native blur.

Atelier is the native successor to Ghostty + tmux + Helix + Claude Code. It hosts claude unchanged and owns the chrome, keyboard, clipboard & notifications itself. Copy from any pane returns the actual text — paragraphs as paragraphs, no gutter-indent leaking in. Use ⌘P to go to a file.
