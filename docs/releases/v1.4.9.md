# Atelier v1.4.9 — 2026-10-07

A project keeps its name when its only open sessions are in a worktree.

## What changed

**Projects keep their name across a relaunch.** If every session left
open in a project was in a worktree, relaunching Atelier renamed the
project after that worktree, on its tab and at the left of the session
bar. Atelier now saves the folder each project was opened on and brings
the project back under that name. Sessions saved by older versions are
fixed on the first relaunch after you update.

**A worktree is never the project's name.** A project whose first
session is in a worktree is named after the repository it belongs to.
This covers reopening a closed worktree session into an empty project
with ⇧⌘T, and opening a worktree folder from the Landing. The worktree
still has its own label, ⎇ and its folder name, in the session bar.
