# Atelier v1.4.4 — 2026-09-26

Renaming a tab widens it as you type.

## What changed

**The pill follows a longer name.** Double-click a session tab and type:
once the name outgrows the tab, the tab widens with each keystroke and
the rest of the row slides along, instead of the text scrolling inside a
fixed box until you press ↩.

It only grows while you type. A shorter name keeps the old width until
you commit, so the row doesn't jump left on your first keystroke; Esc
puts everything back where it was.
