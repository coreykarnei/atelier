# Atelier v1.4.12 — 2026-10-11

The selected project tab is rounder, and its close button stays in view.

## What changed

**A rounder selected project.** The selected tab along the top is now a
pill, fully rounded at both ends.

**The close button is always there.** The selected project's `×` used
to appear only when you pointed at the tab. It now stays visible, dim
until you point at it, the way the selected session's `×` in the bottom
bar already does. Closing a project still keeps its sessions on the
shelf to reopen later.
