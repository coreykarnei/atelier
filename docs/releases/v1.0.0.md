# Atelier v1.0.0 — 2026-09-16

The first tagged release. Atelier has been the author's daily driver since
the workspace milestone; 1.0 marks the point where the editor, the file
explorer, remote sessions and the polish pass are all in and nothing on the
original plan is left open.

## What's in it

**The workspace.** One window; projects as tabs of it, sessions as tabs
within them. Each session is a fixed pane shape — editor, shell, agent —
hosting its own unchanged `claude` process. Tab titles come from Claude's own
session summary. Sessions start from a Landing that promotes in place, and
the window→session tree survives quit and relaunch with agents resuming their
conversations.

**The agent's state, always visible.** Hook-driven notifications carry the
session id: banners click through to the exact tab; tabs wear a dot for
working / waiting / blocked / unseen-done; the Dock badge counts the sessions
that are waiting on you.

**Worktrees.** Starting a session asks which worktree, or names a new one;
tabs group into folders labelled by worktree; the `atelier` CLI (`atelier`,
`-b`, `-rm`) carries the `ide` script's semantics. Tear-down is one
right-click.

**The editor.** A TextKit 2 buffer with incremental tree-sitter highlighting
in the Catppuccin palette — twenty grammar queries rewritten by hand and
gated by the `atelier-hlcheck` harness. A file explorer down the editor's
left edge with a search panel that merges the `⌘P` file offer and ripgrep
text search into one list. Click previews, the first keystroke commits.
Multi-cursor with VSCode chords, `⌘F` seeded from the selection, `⌘P`
go-to-file, LSP go-to-definition and diagnostics with a server registry that
uses whatever is on your login-shell `PATH` (Python servers get the repo's
venv), a file header with `< >` history and markdown preview, autosave, and
a clean buffer that reloads when its file changes on disk.

**Terminals with Ghostty parity.** SwiftTerm is vendored with Atelier's
patches: wheel routing decided by the terminal, SGR motion handled as
motion, Ghostty's ⌘-chords, copy-on-select, OSC 52, remote tmux passthrough.

**Remote sessions.** A session can live on an ssh host; both panes ride
`tmux` on the far side, so link death reattaches on backoff and quitting the
app leaves the work running.

**Truthful copy.** Selecting agent text yields clean logical markdown,
reconstructed from Claude's persisted transcript — the Milestone 0 bet.

**The look.** Catppuccin Mocha, transparent fields over WindowServer blur,
opaque under Reduce Transparency; one overlay material under every floating
surface; a content type scale (`⌘+`/`⌘−`/`⌘0`) that leaves the chrome alone.
And a new icon: a chunky wooden desk under a frosted slate of glowing code.

## Requirements

macOS 14+. Claude Code on `PATH` as `claude`. Optional: `rg`, and any
language servers you already have.

## Building

```sh
make bundle CONFIG=release   # .build/Atelier.app
make install                 # symlink into /Applications
```

The bundle is signed with a local self-signed identity (or ad-hoc). It is
not notarized: on another Mac, right-click → Open once, or
`xattr -dr com.apple.quarantine Atelier.app`.

## Record
