# Atelier v1.1.0 — 2026-09-17

The first day of driving 1.0 turned up a list. This release is that list:
a few things that read wrong, two search bugs that had hidden a lot of
highlights, and one performance fault that stuttered the agent pane.

## What changed

**Every folder carries its own `+`.** The bottom bar's single trailing `+`
gave way to one per worktree folder, seated at the cell's trailing end in a
slot that is always reserved, so hovering never reflows the strip. The glyph
is always drawn: a whisper at rest, full in the active session's folder and
in whichever folder the pointer is over. Clicking it starts a session *there*
— the worktree chooser opens with that worktree preselected, so New… stays
one step from any folder. The active tab's close `×` now rests visible too.

**The file tree resizes.** Drag the tree's edge (a narrow strip on the
hairline, ↔ cursor) between 160 and 560pt; the width is remembered for every
pane and across launches. Double-click the edge to restore the default.

**The project row scrolls.** Tabs floor at 180pt and the row scrolls
sideways instead of folding tabs into an `…` menu; the clipped edge fades and
selecting a tab glides it into view.

**Dividers resize live.** The terminal grid follows the pointer during a
divider drag and the process hears one resize per 50ms, Ghostty-style,
instead of the pane showing raw blur until release.

**The editor is one wash.** The buffer paints its field colour exactly once,
like the terminals — the editor used to compound to near-opaque where the
terminals stayed translucent.

**Previews are read-only.** A single-click preview can be scrolled, selected
and copied, never edited. Double-click in the buffer, `↩` in the tree, or an
editing keystroke enters the file and then applies the key. Before, `⌘X` in
a preview could cut text out of a file you had never entered.

**Search panel.** The highlighted result is what the buffer shows — eagerly
when results land, and following arrows and the pointer. Hits land centred.
Results no longer flicker while the engine is answering. Two bugs that hid
highlights are fixed: the tools report a byte column and the buffer read it
as characters, so any `—` or `⌘` earlier on the line pushed the mark off it;
and the text view built rects for soft-wrapped rows from the wrong offsets,
so a match past the first visual row drew a sliver at the wrap point instead
of the text (a vendored CodeEditTextView fix, meant for upstream).

**Worktree folders keep their label** as the only group left; before,
closing the main session stripped the `⎇` tag.

**Tab titles no longer stutter the app.** Titles come from Claude's
transcripts, which were re-read whole and JSON-parsed on the main thread
every two seconds — 50 MB of transcript froze the agent pane for a quarter
second each tick. They are now read incrementally on a utility queue.

## Requirements

macOS 14+. Claude Code on `PATH` as `claude`. Optional: `rg`, and any
language servers you already have.

## Building

```sh
make bundle CONFIG=release   # .build/Atelier.app
make install                 # symlink into /Applications
```

The bundle is signed with a local self-signed identity (or ad-hoc). It is
not notarized: on another Mac, right-click → Open once, or
`xattr -dr com.apple.quarantine Atelier.app`.
