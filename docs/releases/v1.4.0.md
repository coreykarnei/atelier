# Atelier v1.4.0 — 2026-09-24

Closing a project no longer throws its sessions away, and project tabs
move where you put them.

## What changed

**Closing a project shelves it.** Close Project (`⌥⌘W`, the project tab's
`×`, or the palette) used to end every session in the project. Now it
keeps the project's sessions, stopping them exactly as quitting does
(remote work keeps running on its host). Open the same folder again (from
a new tab's Landing, `⌘↩`, a remote pick, or `atelier <path>`) and every
session comes back where it was, each Claude resuming its conversation.
Shelved projects survive quitting, and nothing expires.

**The Landing shows what's waiting.** Shelved projects lead the list in a
new tab, whether or not they were recent, each wearing one dot per
session in the state it will come back in.

**The old close is still there.** Hold `⌥` over the project tab and the
`×` turns peach: clicking it ends every session, remote ones included,
and forgets the project. The same close is `⇧⌥⌘W`, File → Close Project
and End Sessions, and a palette command.

**Project tabs drag to reorder**, the way session tabs do: the tab lifts
and follows the pointer, and its neighbours step aside. `⌘1`–`⌘9` and
the next launch follow the new order.

## Notes

The shelf lives in `shelf.json` beside `session.json` in
`~/.local/state/atelier/`. New dev probe: `probe:click=x,y[,opt]` clicks
with modifiers held, and `probe:key` now sends real letter key codes.
