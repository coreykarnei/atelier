# Atelier v1.6.0 — 2026-11-15

Terminals reach what's off screen, the editor's pane can become a second
terminal, and a project opens on its README.

## What changed

**Selecting past the edge scrolls.** Drag a selection in a terminal up
past the top of its pane, or down past the bottom, and the pane scrolls
that way with the selection following: slowly just past the edge, faster
the further you reach. Scrolling the wheel while you hold a selection
extends it too. Before, the drag stopped at what was on screen. (Claude
Code in fullscreen mode does its own selecting; this is for the shells.)

**Scrolling a terminal moves by the line.** Two fingers on the trackpad
now move a shell's history with them, at the same feel as Claude's pane.
Before, the smallest movement scrolled a line per event and a quick one
jumped a page, so the line you wanted went past. A mouse wheel moves
three lines a notch.

**Terminals remember 10,000 lines.** They kept 500, so the top of a long
build or test run was gone by the time you scrolled up for it.

**A second terminal, in the editor's pane.** `⌃`` puts a second shell
where the editor is, on the session's folder. The chord works the way it
does in VS Code: press it again from another pane to jump to the
terminal, and from inside the terminal to put it away. The terminal
glyph in the bottom bar, View → Terminal in Editor Pane, and the command
palette do the same. The editor and the shell each stay as you left them
while the other is showing; `exit` closes the shell and brings the editor
back. Opening a file, the explorer or a search brings the editor back as
well. Sessions come back after a relaunch with whichever one they had up.

**`exit` in the shell starts a new one.** The shell pane used to stay
dead for the rest of the session.

**A project opens on its README.** A session with nothing in its editor
shows the folder's README, or its CLAUDE.md if it has no README, as a
read-only preview beside the file tree. Type in it or double-click to
start editing; open anything else and it gets out of the way.

## Notes

The second shell is not restored with its history: a relaunch starts a
new one. New dev probes (debug builds only): `probe:slot`, `probe:text=`,
`probe:second=`, `probe:seldrag=`, `probe:quit`, and a `menu` flag on
`probe:key=`.
