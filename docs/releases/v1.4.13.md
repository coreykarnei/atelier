# Atelier v1.4.13 — 2026-10-12

Closing a project's last session closes the project.

## What changed

**The last session takes its project with it.** Closing a project's
last session (⌘W, or the `×` on its tab in the bottom bar) used to
leave behind an empty "New Tab" project you then had to close as well.
Now the project closes too, and the project beside it takes its place.
A new ⌘T tab you didn't use closes the same way. If it's the only
project open, it still becomes a fresh Landing, so ⌘W never closes the
window or quits the app.

**⌘⇧T brings it back.** Reopen Closed Session returns the project to
its old place in the row, with the session you closed. It always undoes
the most recent close: if you close one project's last session and then
a session somewhere else, ⌘⇧T brings back that session first, and the
project next.
