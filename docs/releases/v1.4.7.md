# Atelier v1.4.7 — 2026-10-07

A project tab's dots now line up with the session bar.

## What changed

**The dots read left to right, like the bar.** The bar groups a
project's sessions by where they run: the main checkout first, then
each worktree, then each remote host. The dots on the project tab
ignored that grouping and went in the order the sessions were opened.
So a session started in a worktree before one on main showed its dot
ahead of main's on top, but its tab after main's below. The dots now
follow the bar exactly, so the third dot is the third tab.

**⌥⌘1…9 count the same way.** Jumping to the Nth session had the same
mismatch and could land on the wrong tab once worktrees were mixed in.
It now goes to the Nth tab you can see in the bar.
