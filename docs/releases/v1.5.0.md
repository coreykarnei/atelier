# Atelier v1.5.0 — 2026-10-20

A security pass, and remote sessions are gone.

## What changed

**Remote sessions are removed.** Atelier is a local terminal, editor and
Claude host again. Sessions on ssh hosts, the host picker on the Landing,
`host:dir` queries and `@host` folders are gone. A saved workspace or
shelved project that still lists a remote session opens without it; the
local sessions beside it come back as before.

**A folder's own code waits until you trust it.** Opening a folder used to
run things the folder brings: `git status` runs a repository's clean
filters, a language server runs build scripts (rust-analyzer runs
`build.rs`), and the Python server runs the folder's virtualenv. Now
those wait until the folder is trusted. The trust is Claude's: when Claude
asks "Do you trust the files in this folder?" and you say yes, the file
tree's git colours and the language server switch on within a couple of
seconds. Folders you've already trusted in Claude work as they did. A
folder Claude hasn't asked about shows a small lock in the file tree's
header; click it to trust the folder from Atelier. Creating or removing a
worktree in an untrusted repository asks first. Only a folder's own
answer counts, not a parent's — trusting your home folder doesn't trust
everything in it.

**Opening something that runs asks first.** ⌘-clicking a path or link in
a terminal, or clicking a link in the Markdown preview, now asks before
opening an app, an installer, a script, an executable, a file that opens
in a terminal, or a link meant for another app. The question names the
full target, since a terminal link's text can say something else. Web
pages, mail links and ordinary files open as before.

**Pastes are cleaned.** Pasting into a terminal drops control characters,
so copied text can't smuggle in an escape sequence that runs part of it as
if you'd typed it.

**When a program sets the clipboard, you see it.** If something running in
a pane (Claude's copy, a tool using OSC 52) puts text on the clipboard, the
pane says so for two seconds: "Claude set the clipboard · 42 characters".
Your own copies stay silent.

**Under the hood.**
- Atelier's socket and state files are readable by your account only, and
  the saved workspace is written atomically.
- One misbehaving connection can no longer stall notifications or quit.
- Shells and Claude no longer inherit the app's socket or other sessions'
  terminals.
- Every `git` Atelier runs ignores a repository's `core.fsmonitor`.
- The developer probe surface is no longer in release builds.
- Release builds pin their dependencies, refuse an uncommitted tree, and no
  longer run a lint plugin.

## If you used remote sessions

Atelier set some things up on each host. They're harmless where they are,
but here is what to remove:

- `~/.local/bin/atelier-notify` (a Python helper).
- Seven hook entries in the host's `~/.claude/settings.json` that run
  `~/.local/bin/atelier-notify <verb>`: Stop, two Notification matchers,
  UserPromptSubmit, PostToolUse, PostToolUseFailure and SessionStart.
  `~/.claude/settings.json.atelier-bak` is the backup taken before the
  first change.
- `~/.local/state/atelier/` (`provisioned-v1` … `v5` markers and a stale
  socket) and `~/.config/atelier/tmux-v*.conf`.
- A tmux server Atelier may have left running, possibly still running
  Claude: check with `tmux -L atelier ls` and end it with
  `tmux -L atelier kill-server`.

Your conversations under `~/.claude/projects/` stay where they are.
