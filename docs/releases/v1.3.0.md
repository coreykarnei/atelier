# Atelier v1.3.0 — 2026-09-23

The status dots got honest, the terminals got faster, and quitting stopped
losing work. Most of it came from living in the app for two days: a dot
that stayed peach after a prompt was answered, blue after an interrupt, or
missing entirely after a `/resume`; a relaunch that came back empty.

## What changed

**The close button keeps your sessions.** The red button used to tear
every project down one by one and then quit with nothing left to save, so
the next launch opened a blank Landing. It now quits exactly as `⌘Q`
does: the dirty-buffer guard, the snapshot, remote work left running.

**Claude gets your shell environment.** A GUI app starts with launchd's
bare environment, and Claude was spawned with no `PATH` at all — its Bash
tool couldn't find `head`, and MCP servers launched through `npx` failed.
Atelier now captures what an interactive login shell builds (`PATH`,
`SSH_AUTH_SOCK`, `TMPDIR` and the rest) at launch and hands it to every
local Claude.

**When Claude exits, the pane offers the way back in.** `/exit`, a crash
or a kill used to leave a dead terminal. The pane now raises a card:
`↩` resumes the same conversation, `⇧↩` starts a new one in the same tab.

**Dots that tell the truth.**
- *Peach clears when you answer.* Claude Code has no hook for an approved
  permission, so the dot stayed peach until the turn ended. Atelier now
  listens for the tool finishing (new `PostToolUse` hooks) and reads the
  answer as you type it — `↩` or a digit is back to blue, `Esc` is green.
- *An interrupt turns the dot green.* `Esc` or `⌃C` mid-turn fires no hook
  at all; the transcript's interrupt marker now does the job, within
  about two seconds.
- *A tab follows its conversation.* `/resume` or `/clear` inside Claude
  switch its session id, and the tab used to lose track — no title, no
  dot. Every agent now carries its tab's identity, so title, dots and
  relaunch follow the conversation.
- *Unseen marks ring.* A completion or a block that lands while you're
  elsewhere gives off a hairline ring in its colour, in step with every
  other ringing dot, until you look.

**Project-tab dots are doors.** Each dot on a project tab is now a button —
bigger, with a pointing hand and a tooltip naming the session and how long
it has been waiting — that takes you straight to that session.

**`⌥⌘1`–`⌥⌘9` jump to sessions**, in bar order, the way `⌘1`–`⌘9` jump
to projects.

**The selected tab's `×` takes its dot's place.** The status dot on the
tab you're already in was the least useful and, green on green, the
least legible; the close button now sits in its slot, so selecting a tab
no longer reflows the row.

**Bottom-bar tooltips open upward**, above the control instead of off the
bottom of the screen, and the `+` reads simply "New Session".

**Faster terminals.** Each terminal now remembers the rows it has drawn
and skips rebuilding and reshaping any row that has only moved, so
scrolling Claude's history costs roughly half what it did (about 22ms a
frame down to 12–15ms). Dragging the window edge now resizes the
terminals on the same throttled beat divider drags use. (Vendored
SwiftTerm patch 10.)

**Typing returns to the live view.** Text typed while scrolled back a
little could land below the bottom edge; any keystroke now snaps to the
live view, as in iTerm2 and Ghostty. (Vendored SwiftTerm patch 9.)

## Upgrading

The hook fragment gained `PostToolUse` and `PostToolUseFailure` entries
(`atelier-notify tool`). Install this build's helper **before** merging
them into `~/.claude/settings.json` — an older helper reads the new verb
as `stop`. Remote hosts re-provision themselves. See `docs/SETUP.md`.

## Notes

New dev probes over the socket: `probe:liveresize`, `probe:scroll`,
`probe:rowcache`, `probe:type` and `probe:tip`.
