# Atelier v1.4.10 — 2026-10-10

The session bar stays readable at any transparency, and a fresh launch
leaves nothing behind when the Landing gives way.

## What changed

**The bars stay readable at high transparency.** With the window's
opacity turned well down in Settings and a light window behind
Atelier, the session bar's clock, layout and settings buttons, and its
`+` all but disappeared. The session bar and the project tabs along
the top now stay at least as opaque as the default setting, however
far the slider goes; below that, only the panes get more transparent.
The clock and the bar's buttons are also drawn in the same color as
the session titles, instead of a dimmer gray.

**No ghost of the Landing.** After a fresh launch, once you opened a
project from the Landing, a faint outline of the Landing's card could
stay visible behind the panes for the rest of the session. It was the
window's shadow, still shaped like the card; Atelier now refreshes it
once the project is on screen.

**The shell starts on its first line.** Opening a project from the
Landing left the shell's prompt two lines down, under blank lines.
The shell is now resized for its pane before it changes directory, so
the prompt starts at the top.

**One Atelier per session folder.** A second copy of Atelier started
against the same session folder, such as a development build, could
take over the running copy's connection to Claude Code's hooks, so
session dots stopped updating until a relaunch. A second copy now
quits before touching anything, and the running copy reconnects at
once if its connection is removed.
